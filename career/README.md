# Career workspace

This folder is a living source of truth for career materials. Update it whenever a project, responsibility, result, certification, or new skill is completed.

## Files

- [`resume.md`](resume.md) — the current resume draft.
- [`skills.md`](skills.md) — skills, evidence, and areas to strengthen.

## Keeping it current

When something meaningful happens, add it to the relevant file while the details are fresh. Capture the context, what you did, the tools or skills involved, and measurable results where possible. Review this folder before applying for a role and tailor the resume from this source of truth.
